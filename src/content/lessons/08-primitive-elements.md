## You'll learn

- A primitive element $\alpha$ has powers that visit every nonzero element, so multiplication becomes adding exponents.
- Log tables for small fields.
- Testing primitivity without trying every power: $\alpha^{(p^k - 1)/r} \ne 1$ for each prime $r \mid p^k - 1$.
